# 魔方拼图

一个纯浏览器端运行的魔方拼图生成工具。用户上传图片并设置可使用的魔方数量后，工具会自动计算合适的排列比例，将图片裁剪、像素化并量化为标准魔方六色，随后生成整体拼图、逐颗魔方拆解信息和可打印的图像切片。

## 功能

- 支持 JPG、JPEG、PNG 和 WebP 图片
- 根据图片比例和魔方数量上限自动计算排列
- 支持居中、顶部、底部、左侧和右侧裁剪
- 使用 CIELAB 色彩空间匹配标准魔方六色
- 可选 Floyd–Steinberg 颜色抖动
- 显示贴纸细网格和魔方粗边界
- 支持显示魔方编号及完成状态
- 九个贴纸颜色完全相同的魔方自动标记为已完成
- 提供逐颗魔方的 3×3 拼装视图
- 支持编号跳转、上一颗和下一颗导航
- 使用浏览器 `localStorage` 保存拼装进度
- 统计六种颜色所需的贴纸数量
- 导出高清整体 PNG
- 按整体图像位置生成 A4 打印切片
- 打印文件最后附带完整切片位置索引
- 支持深色和浅色界面

## 使用方法

1. 打开网页。
2. 上传需要转换的图片。
3. 输入最多可使用的魔方数量。
4. 根据需要选择颜色抖动和裁剪方式。
5. 点击“生成魔方拼图”。
6. 在整体拼图中检查效果，或进入拼装模式逐颗完成。
7. 根据需要导出整体 PNG，或打印／保存 PDF 图像切片。

每颗标准 3×3 魔方提供 9 个贴纸色块。例如，`18 × 11` 颗魔方对应 `54 × 33` 个逻辑像素。

## 颜色

工具只使用以下六种标准魔方颜色：

- 白色
- 黄色
- 红色
- 橙色
- 蓝色
- 绿色

调色板参数集中定义在 HTML 文件的 `PALETTE` 对象中，可以根据实际魔方贴纸颜色调整 HEX 和 RGB 数值。

## 本地运行

项目不需要安装依赖或启动服务器。下载 `index.html` 后，使用现代浏览器直接打开即可。

推荐使用：

- Google Chrome
- Microsoft Edge
- Safari
- Firefox

## 部署到 GitHub Pages

1. 创建一个公开 GitHub 仓库。
2. 将工具 HTML 文件重命名为 `index.html`。
3. 把 `index.html` 和本文件 `README.md` 上传到仓库根目录。
4. 打开仓库的 `Settings → Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. 选择 `main` 分支和 `/(root)` 目录。
7. 保存并等待 GitHub Pages 完成发布。

发布地址通常为：

```text
https://<你的GitHub用户名>.github.io/<仓库名称>/
```

## 隐私

所有图片处理均在用户浏览器中完成：

- 上传的图片不会发送到服务器
- GitHub Pages 只负责提供静态网页文件
- 拼装进度仅保存在当前浏览器的 `localStorage` 中
- 清除浏览器网站数据后，本地拼装进度会消失

## 技术实现

- HTML5 Canvas
- 原生 JavaScript
- CSS
- CIELAB 颜色量化
- Floyd–Steinberg Dithering
- LocalStorage

项目为单文件静态应用，不依赖后端、数据库或第三方运行时。

## 注意事项

- 颜色量化结果受原图光线、对比度和魔方贴纸实际颜色影响。
- 开启颜色抖动可以改善渐变和照片层次，但近距离观察时颗粒感会更明显。
- 图片比例与魔方排列比例不同时，工具会根据所选对齐方式裁剪图片，不会强制拉伸。
- 打印 PDF 时建议选择 A4、纵向、实际尺寸或 100% 缩放，并关闭浏览器页眉和页脚。
